# Improving Candidate Placement Success Rate | Data Analysis & Visualization

## Project Overview
This project focuses on analyzing candidate placement data to identify the key factors influencing placement success. The objective is to understand how academic performance, technical skills, practical experience, and soft skills contribute to placement outcomes.

The analysis aims to help hiring platforms improve candidate shortlisting, guide student preparation strategies, and support recruiters in making data-driven decisions.

## Business Objectives
- Identify key factors influencing candidate placement.
- Analyze the relationship between academic performance and placement outcomes.
- Evaluate the impact of internships, projects, certifications, and technical skills.
- Identify high-potential candidate segments.
- Provide actionable recommendations to improve placement success rates.

## Dataset Overview
- **Total Records:** 1,000,000
- **Total Features:** 30
- **Target Variable:** Placed (0/1)

The dataset includes:
- **Academic Factors:** CGPA, attendance, and backlogs.
- **Technical Skills:** Python, Java, Machine Learning, and Web Development.
- **Practical Experience:** Internships, projects, and certifications.
- **Soft Skills:** Communication, teamwork, and leadership.

## Key Performance Indicators (KPIs)
**North Star Metric:**
- Placement Success Rate = Placed Students / Total Students

**Supporting Metrics:**
- Average CGPA
- Average Aptitude Score
- Average Number of Internships
- Average Coding Rating
- Average Certifications

## Analysis Performed
- Explored candidate placement distribution.
- Analyzed placement rates across different candidate performance segments.
- Compared placement outcomes across academic branches.
- Examined correlations between candidate attributes and placement outcomes.
- Identified factors associated with higher and lower placement success.

## Key Findings
1. Candidates with higher academic and overall performance scores demonstrated better placement outcomes.
2. Internships and practical project experience showed positive relationships with placement success.
3. Aptitude and communication skills contributed to placement outcomes.
4. Backlogs showed a negative relationship with placement success.
5. Technical skills and practical exposure were important factors associated with stronger candidate profiles.

## Business Recommendations
- Prioritize practical learning through internships and projects.
- Strengthen aptitude and communication skills through targeted training.
- Encourage candidates to develop relevant technical skills.
- Provide additional preparation support to candidates with weaker profiles.
- Use candidate segmentation to improve recruiter targeting and shortlisting.

## Tools & Technologies
- Python
- SQL
- Tableau

## Conclusion
The analysis highlights the importance of evaluating candidates beyond academic performance alone. Academic achievements, technical capabilities, practical exposure, and behavioural skills collectively provide valuable insights into placement outcomes.

The findings can help hiring platforms develop targeted preparation strategies, improve candidate shortlisting, and enhance recruiter efficiency.
